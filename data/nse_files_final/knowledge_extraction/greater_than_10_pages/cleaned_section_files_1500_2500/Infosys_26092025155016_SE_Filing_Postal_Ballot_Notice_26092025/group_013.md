## NSDL Mobile App is available on

| Type of shareholders | Login Method |
|---|---|
| Individual Shareholders holding securities in demat mode with CDSL | Users registered for CDSL Easi/Easiest can log in with their existing user ID and password and access the e-Voting page without further authentication. After logging in, eligible companies with e-Voting in progress will be displayed. Shareholders can select the e-Voting option to access the e-Voting service provider’s page and cast their vote. Unregistered users can register through the CDSL website. Alternatively, shareholders can access the e-Voting page from the CDSL website using their demat account number and PAN. Authentication is completed through an OTP sent to the mobile number and email address registered with the demat account. |
| Individual Shareholders holding securities in demat mode and logging in through their depository participants | Shareholders can use the login credentials for their demat account through a depository participant registered with NSDL/CDSL for e-Voting. After authentication, select the e-Voting option, the company name or NSDL as the e-Voting service provider, and proceed to the NSDL e-Voting website to cast the vote during the remote e-Voting period. |

Members who cannot retrieve their user ID or password can use the “Forget User ID” and “Forget Password” options available on the relevant website.

## Helpdesk for Individual Shareholders holding securities in demat mode for any technical issues related to login through Depository i.e., NSDL and CDSL.

Technical assistance is available through the NSDL and CDSL e-Voting helpdesk channels specified in the notice.

## B) Login Method for shareholders other than Individual shareholders holding securities in demat mode and shareholders holding securities in physical mode.

### How to Log-in to NSDL e-Voting website?

1. Visit the NSDL e-Voting website at https://www.evoting.nsdl.com/ using a personal computer or mobile device.
2. Select **Login** under the **Shareholder/Member** section.
3. Enter the user ID, password/OTP, and verification code. Shareholders registered for NSDL IDeAS can alternatively log in at https://eservices.nsdl.com/, select **e-Voting**, and proceed to cast their vote.
4. Shareholders can use the user ID formats shown below.
5. Shareholders already registered for e-Voting can use their existing password.
6. Shareholders using the NSDL e-Voting system for the first time must retrieve the initial password communicated to them and then change it when prompted.
7. If the email ID is registered with the demat account or company, the initial password is sent by email in a PDF attachment. The PDF password is:
   - The 8-digit client ID for an NSDL account.
   - The last 8 digits of the client ID for a CDSL account.
   - The folio number for shares held in physical form.
8. If the email ID is not registered, shareholders should follow the process specified in the notice for unregistered email IDs.
9. If the initial password was not received, cannot be retrieved, or has been forgotten:
   - Demat shareholders can select **Forgot User Details/Password?** on the NSDL e-Voting website.
   - Physical shareholders can select **Physical User Reset Password?** on the NSDL e-Voting website.
   - Shareholders can request assistance from NSDL by providing their demat account number or folio number, PAN, name, and registered address.
   - Shareholders can use OTP-based login to cast their votes.
10. Accept the **Terms and Conditions** by selecting the checkbox.
11. Select **Login**.
12. The e-Voting home page will open.

| Manner of holding shares, i.e., Demat (NSDL or CDSL) or Physical | Your User ID is: |
|---|---|
| a) For Members who hold shares in demat account with NSDL | 8-character DP ID followed by 8-digit Client ID. For example, if the DP ID is `IN300***` and the Client ID is `12******`, the user ID is `IN300***12******`. |
| b) For Members who hold shares in demat account with CDSL | 16-digit Beneficiary ID. For example, if the Beneficiary ID is `12**************`, the user ID is `12**************`. |
| c) For Members holding shares in Physical Form | EVEN number followed by the folio number registered with the company. For example, if the folio number is `001***` and the EVEN is `101456`, the user ID is `101456001***`. |
